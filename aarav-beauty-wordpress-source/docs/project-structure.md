# Project Structure

## `components/`
Reusable Site Editor template-part source.

- `header.html` — responsive navigation, branding and booking CTA
- `footer.html` — navigation, service links, contact information and legal links

## `pages/`
Full Gutenberg Code Editor source for individual WordPress pages. CSS is scoped per page to reduce cross-page styling conflicts.

## `templates/`
Site Editor template source used globally for normal pages.

## `assets/branding/`
Project-owned branding assets included with the repository.

## `docs/`
Implementation notes and future portfolio screenshots.
